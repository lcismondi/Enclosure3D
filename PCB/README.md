# Pinout

![Componentes internos](./Imagenes/Enclosure3D%20Perspectiva%20Componentes.png)

## Rotary encoder
* Switch: 13 [D7]
* Data:   12 [D6]
* Clock:  16 [D0]

## Salidas
* Iluminación:  15 [D8]
* Ventilador 1: 0  [D3]
* Ventilador 2: 14 [D5]

## Sensor
* Humedad y temperatura: 2 [D4]

## Display
* Reset: 16 [D0]
* Clock: 5  [D1]
* Data:  4  [D2]
